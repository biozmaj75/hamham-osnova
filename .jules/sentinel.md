## 2026-11-11 - Static Server Path Traversal and Directory Boundary Check
**Vulnerability:** The static file handler in `local/server.mjs` performed a boundary check using `p.startsWith(SITE)` without appending a path separator (`path.sep`). If the site folder was located in a directory alongside other directories with matching prefixes (e.g., `/var/site` vs `/var/site_secrets`), or had unhandled encoded traversal sequences and null bytes, path traversal or arbitrary file read risks were possible. Additionally, `decodeURIComponent` lacked exception handling for malformed percent encodings.
**Learning:** `p.startsWith(ROOT)` is vulnerable to sibling-prefix bypasses (e.g. `/var/site` matches `/var/site-backup`). Furthermore, raw `decodeURIComponent` can throw on malformed inputs and does not reject embedded null bytes (`\0`).
**Prevention:** Always verify paths against a trailing separator boundary (`p === SITE || p.startsWith(SITE + path.sep)`), handle URI decoding exceptions gracefully, reject null bytes, and include standard HTTP hardening headers (`X-Frame-Options`, `Referrer-Policy`, `X-Content-Type-Options`).
