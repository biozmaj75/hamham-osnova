Dom Obroki – namestitev na lasten računalnik

Navodila za Windows in Linux · za skrbnika sistema

Dom Obroki lahko poleg oblačne različice teče tudi na običajnem računalniku ali strežniku v domu. Potrebujete:

  • Node.js različice 22 ali novejše (izvaja aplikacijo),
  • PostgreSQL (podatkovna baza, različica 14 ali novejša),
  • datoteke aplikacije (mapa z datotekami package.json, local, functions, site).

Strojne zahteve so skromne: 2 jedri, 2–4 GB RAM in nekaj GB prostora na disku zadoščajo za dom s stotinami dijakov. Računalnik mora biti prižgan ves čas, ko aplikacijo uporabljate.

Lokalna namestitev je ločena od oblačne. Ima svojo bazo, svoje uporabnike in svoje podatke. Če želite podatke iz oblačne različice prenesti v lokalno, nam pišite – pripravimo izvoz baze, ki ga uvozite z ukazom pg_restore (poglavje 4).

Kje dobim datoteke

  • Na GitHubu (zasebni repozitorij biozmaj75/hamham-osnova): prijavite se z računom, ki ima dostop, kliknite zeleni gumb Code → Download ZIP in ZIP razširite.
  • Ali pa nas prosite za pripravljen ZIP »dom-obroki-lokalno.zip«.

Mapa web vsebuje izvorno kodo uporabniškega vmesnika in za delovanje ni potrebna – zgrajena aplikacija je že v mapi site.

1. Namestitev na Windows (10, 11 ali Windows Server)

Korak 1. Namestite Node.js

  1. Odprite https://nodejs.org in prenesite različico LTS (Windows Installer, .msi).
  2. Namestitev zaženite in pustite privzete nastavitve (tudi »Add to PATH«).
  3. Preverite: odprite Ukazni poziv (Start → vpišite cmd) in vpišite node -v. Izpisati se mora v22… ali višja številka.

Korak 2. Namestite PostgreSQL

  1. Odprite https://www.postgresql.org/download/windows/ in prenesite namestitveni program (»Download the installer«, EDB) za zadnjo različico.
  2. Med namestitvijo:
    • komponente: dovolj so PostgreSQL Server in Command Line Tools (pgAdmin je neobvezen),
    • določite geslo za skrbniškega uporabnika postgres in si ga zapišite na varno,
    • vrata pustite 5432, »Stack Builder« na koncu ni potreben.
  3. PostgreSQL se namesti kot Windows storitev in se samodejno zažene ob vsakem vklopu računalnika.

Korak 3. Ustvarite bazo za aplikacijo

V meniju Start odprite SQL Shell (psql). Na vprašanja za Server, Database, Port in Username pritisnite Enter, nato vpišite geslo uporabnika postgres. Vpišite (geslo IzberiteGeslo123 zamenjajte s svojim):

CREATE USER obroki WITH PASSWORD 'IzberiteGeslo123';
CREATE DATABASE obroki OWNER obroki;
\q
Za geslo baze uporabite le črke in številke (brez @ : / % #), sicer ga je treba v naslovu baze posebej kodirati.

Korak 4. Prenesite aplikacijo in jo nastavite

  1. Razširite ZIP v mapo, npr. C:\DomObroki (tako da je datoteka C:\DomObroki\package.json).
  2. V mapi C:\DomObroki\local naredite kopijo datoteke nastavitve.env.primer in jo preimenujte v nastavitve.env. (V Raziskovalcu vklopite Pogled → Pripone imen datotek, da datoteka ne dobi imena nastavitve.env.txt.)
  3. Datoteko nastavitve.env odprite z Beležnico in v vrstici DATABASE_URL besedo GESLO zamenjajte z geslom iz koraka 3: 
    DATABASE_URL=postgres://obroki:IzberiteGeslo123@localhost:5432/obroki
DATABASE_SSL=off
HOST=127.0.0.1
PORT=8080
Datoteka nastavitve.env vsebuje geslo baze. Ne pošiljajte je po e-pošti in je ne kopirajte na skupne mape.

Korak 5. Namestite knjižnice in ustvarite administratorja

Odprite Ukazni poziv in vpišite:

cd C:\DomObroki
npm install --omit=dev
npm run admin

Program npm run admin ob prvem zagonu ustvari tabele v bazi in vpraša za uporabniško ime, ime in priimek ter geslo (vsaj 8 znakov) prvega administratorja.

Korak 6. Zaženite aplikacijo

Dvokliknite C:\DomObroki\local\zazeni.bat. Odpre se črno okno z izpisom

Dom Obroki teče na http://localhost:8080  (ustavite s Ctrl+C)

V brskalniku odprite http://localhost:8080 in se prijavite z administratorjem iz koraka 5. Okno mora ostati odprto, dokler aplikacijo uporabljate.

Nato v aplikaciji: Nastavitve (šolsko leto, časi obrokov), Uporabniki (računi za zaposlene), Dijaki → Uvozi seznam in Jedilnik. Podrobnosti so v Uporaba.pdf.

Korak 7. Samodejni zagon ob vklopu računalnika (priporočeno)

Da aplikacija teče tudi, ko nihče ni prijavljen v Windows, jo registrirajte kot opravilo. Odprite PowerShell kot skrbnik (desni klik na Start → Terminal (skrbnik)) in vpišite:

$a = New-ScheduledTaskAction -Execute "C:\Program Files\nodejs\node.exe" -Argument "C:\DomObroki\local\server.mjs"
$t = New-ScheduledTaskTrigger -AtStartup
$s = New-ScheduledTaskSettingsSet -ExecutionTimeLimit ([TimeSpan]::Zero) -RestartCount 5 -RestartInterval (New-TimeSpan -Minutes 1)
Register-ScheduledTask -TaskName "Dom Obroki" -Action $a -Trigger $t -Settings $s -User "SYSTEM" -RunLevel Highest
Start-ScheduledTask -TaskName "Dom Obroki"

Opravilo vidite v Razporejevalniku opravil (Task Scheduler). Ustavite ga z Stop-ScheduledTask -TaskName "Dom Obroki". Ko teče kot opravilo, okna zazeni.bat ne zaganjajte hkrati (vrata bi bila zasedena).

2. Namestitev na Linux (Ubuntu / Debian)

Navodila veljajo za Ubuntu 24.04 ali novejši in Debian 12 ali novejši. Ukaze vpisujete v terminal kot uporabnik s pravico sudo. Za AlmaLinux / Rocky namesto apt uporabite dnf (paketa nodejs in postgresql-server, nato sudo postgresql-setup --initdb).

Korak 1. Node.js in PostgreSQL

sudo apt update
sudo apt install -y curl unzip postgresql
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
node -v          # mora biti v22 ali višje

(Če ima distribucija v svojih paketih Node.js 22 ali novejši, zadošča sudo apt install nodejs npm.)

Korak 2. Baza

sudo -u postgres psql -c "CREATE USER obroki WITH PASSWORD 'IzberiteGeslo123';"
sudo -u postgres psql -c "CREATE DATABASE obroki OWNER obroki;"

Korak 3. Sistemski uporabnik in datoteke

sudo useradd --system --home /opt/dom-obroki --shell /usr/sbin/nologin obroki
sudo mkdir -p /opt/dom-obroki
sudo unzip dom-obroki.zip -d /tmp/dom-obroki     # ali git clone
sudo cp -r /tmp/dom-obroki/*/. /opt/dom-obroki/   # vsebina mape s package.json
cd /opt/dom-obroki
sudo cp local/nastavitve.env.primer local/nastavitve.env
sudo nano local/nastavitve.env                    # vpišite geslo baze
sudo chown -R obroki:obroki /opt/dom-obroki
sudo chmod 600 local/nastavitve.env

Korak 4. Knjižnice in prvi administrator

cd /opt/dom-obroki
sudo -u obroki npm install --omit=dev
sudo -u obroki npm run admin

Korak 5. Preizkus in stalna storitev

Hiter preizkus: sudo -u obroki ./local/zazeni.sh in v brskalniku http://localhost:8080 (ustavite s Ctrl+C). Za stalno delovanje uporabite priloženo systemd storitev:

sudo cp /opt/dom-obroki/local/dom-obroki.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now dom-obroki
systemctl status dom-obroki          # stanje
journalctl -u dom-obroki -f          # dnevnik (izhod s Ctrl+C)

Storitev se zažene ob vklopu strežnika in se po morebitni napaki sama znova zažene. Če je node nameščen drugje kot /usr/bin/node (preverite z which node), popravite vrstico ExecStart.

3. Dostop z drugih računalnikov

Privzeto (HOST=127.0.0.1) je aplikacija dosegljiva samo na računalniku, kjer teče. Da jo odprete tudi z drugih računalnikov v domu, v nastavitve.env nastavite HOST=0.0.0.0, odprite vrata v požarnem zidu in aplikacijo ponovno zaženite. Natančna navodila – lokalno omrežje, domena, dostop od zunaj, internet in Arnesov strežnik – so v ločenem dokumentu Mreža.pdf.

4. Varnostne kopije in obnova

Za varnostne kopije lokalne namestitve skrbite sami. Brez njih okvara diska pomeni izgubo vseh podatkov.

Windows

Ustvarite mapo C:\Varnostne in z Beležnico datoteko C:\DomObroki\local\kopija.ps1 z vsebino (številko 18 zamenjajte z nameščeno različico PostgreSQL):

$env:PGPASSWORD = 'IzberiteGeslo123'
& "C:\Program Files\PostgreSQL\18\bin\pg_dump.exe" -h localhost -U obroki -F c -f "C:\Varnostne\obroki-$(Get-Date -Format yyyy-MM-dd).dump" obroki
Get-ChildItem C:\Varnostne\obroki-*.dump | Where-Object LastWriteTime -lt (Get-Date).AddDays(-60) | Remove-Item

Vsakodnevno kopijo ob 22.00 nastavite v PowerShellu (kot skrbnik):

$a = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-ExecutionPolicy Bypass -File C:\DomObroki\local\kopija.ps1"
Register-ScheduledTask -TaskName "Dom Obroki kopija" -Action $a -Trigger (New-ScheduledTaskTrigger -Daily -At 22:00) -User "SYSTEM"

Kopije, starejše od 60 dni, se brišejo same. Datoteke iz C:\Varnostne redno kopirajte na drug disk, NAS ali v oblak (npr. Arnes Shramba). Ker kopija.ps1 vsebuje geslo baze, naj bo dostopna le skrbnikom.

Linux

sudo mkdir -p /var/backups/obroki && sudo chown postgres /var/backups/obroki
echo '30 22 * * * postgres pg_dump -F c -f /var/backups/obroki/obroki-$(date +\%F).dump obroki && find /var/backups/obroki -mtime +60 -delete' | sudo tee /etc/cron.d/dom-obroki

Obnova iz kopije

pg_restore -h localhost -U obroki -d obroki --clean --if-exists obroki-2026-11-02.dump

Pred obnovo aplikacijo ustavite in jo po obnovi spet zaženite.

5. Vzdrževanje

Pozabljeno geslo administratorja

Na strežniku v mapi aplikacije zaženite npm run admin (Linux: sudo -u obroki npm run admin), vpišite uporabniško ime in novo geslo. Račun se hkrati odklene.

Posodobitev na novo različico

  1. Naredite varnostno kopijo baze (poglavje 4) in ustavite aplikacijo.
  2. Nove datoteke skopirajte čez stare – datoteke local/nastavitve.env ne prepišite.
  3. Zaženite npm install --omit=dev in aplikacijo znova zaženite (Linux: sudo systemctl restart dom-obroki). Morebitne spremembe tabel se izvedejo samodejno.
  4. Uporabniki naj v brskalniku stran osvežijo (F5).
